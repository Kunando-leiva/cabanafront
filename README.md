CabanaFront es una aplicación web desarrollada con React y creada con Create React App.
Su propósito es servir como frontend para la gestión y visualización de información relacionada con el proyecto Cabaña.

🚀 Requisitos previos
Antes de comenzar, asegúrate de tener instalado:
• 	Node.js (versión recomendada: 18 o superior)
• 	npm o yarn como gestor de paquetes
• 	Un navegador moderno (Chrome, Edge, Firefox, Safari)

⚙️ Instalación
Clona el repositorio y entra en la carpeta del proyecto:
git clone https://github.com/Kunando-leiva/cabanafront.git
 cd cabanafront

Instala las dependencias:
npm install

Scripts disponibles
En el directorio del proyecto, puedes ejecutar:
• npm star → Inicia la aplicación en modo desarrollo.
Abre http://localhost:3000 en tu navegador.
• npm test → Ejecuta los tests en modo interactivo.
• npm run build → Genera la versión optimizada para producción en la carpeta .
• npm run eject → Expone la configuración interna de CRA (Webpack, Babel, ESLint). ⚠️ Irreversible.

📂 Estructura del proyecto
- public/ → Archivos estáticos (index.html, favicon, etc.)
- src/ → Código fuente principal
- components/ → Componentes reutilizables
- pages/ → Vistas principales
- services/ → Conexión con APIs
- styles/ → Estilos globales
- App.js → Componente raíz
- index.js → Punto de entrada
- package.json → Configuración y dependencias
- README.md → Documentación del proyecto


📦 Dependencias principales
• 	React – Librería principal para la UI
• 	React Router – Navegación entre páginas
• 	Axios / Fetch – Consumo de APIs
• 	Bootstrap / Material UI / Tailwind – (dependiendo de lo que uses para estilos)
